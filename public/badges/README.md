# 成就徽章图片资源

把徽章 PNG 放在本目录，文件名必须与徽章 id 一一对应（见下表）。
未放入图片时，界面会自动回退为对应的 lucide 图标占位，不会报错。

建议尺寸：正方形 ≥ 256×256（建议 512×512），透明背景 PNG。
未达成状态的徽章会自动应用灰度滤镜，因此只需提供「点亮态」图片。

| 文件名 | 徽章 | 获得条件 |
| --- | --- | --- |
| `night-owl.png` | 夜猫子 | 本地时间 0–6 点提交 ≥ 100 次 |
| `early-bird.png` | 早起鸟 | 本地时间 5–8 点提交 ≥ 100 次 |
| `fullstack-explorer.png` | 全栈探索者 | 累计使用 ≥ 5 种语言 |
| `language-master.png` | 语言大师 | 累计使用 ≥ 10 种语言 |
| `oss-contributor.png` | 开源贡献者 | 向 ≥ 3 个非自有仓库贡献过提交 |
| `power-coder.png` | 码力全开 | 单日提交 ≥ 20 次 |
| `streak-king.png` | 连续提交王 | 连续 30 天有提交 |
| `hundred-day.png` | 百日坚持 | 连续 100 天有提交 |
| `thousand-commits.png` | 千提交 | 累计提交 ≥ 1000 次 |
| `tenk-lines.png` | 万行代码 | 累计新增 ≥ 10000 行 |
